# Part 3: 技能システム・難易度・CP計算・技能なし値

## 3.1 基本構造
- 技能レベル = 関連能力値 + 習得相対レベル
- 基準属性: DX(運動/格闘/射撃)、IQ(知識/学術/魔法/技術)、HT(スタミナ/水泳)、Will/Per(意志/知覚)

## 3.2 技能コスト表
| 相対レベル | E | A | H | VH |
|---|---|---|---|---|
| -4 | - | - | - | 1CP |
| -3 | - | - | 1CP | 2CP |
| -2 | - | 1CP | 2CP | 4CP |
| -1 | 1CP | 2CP | 4CP | 8CP |
| +0 | 2CP | 4CP | 8CP | 12CP |
| +1 | 4CP | 8CP | 12CP | 16CP |
| +2 | 8CP | 12CP | 16CP | 20CP |
| 以降+1 | +4CP | +4CP | +4CP | +4CP |

- 万能技能(Wildcard/!): VH×3、範囲技能一括代用

## 3.3 技能なし値
- E:-4 / A:-5 / H:-6 / VH:-7または不可
- 他技能基準: 類似技能からペナルティ差
- 20の法則: 能力値>20は20扱い

## 3.4 TL依存技能
- /TL識別子
- TL不一致: 1差につき-5
- 専門化: 必須(操縦/機種) / 自発(難度1段階低下)

## 3.5 テクニック
- 基本技能前提、A(1CP→+1) / H(2CP→+1)、上限=基本技能値
