# Part 5: 負傷・回復・環境・移動・荷重

## 5.1 荷重
- BL=ST²/10(kg) or ST²/5(lbs)
- 無(×1) / 軽(×0.8,-1) / 並(×0.6,-2) / 重(×0.4,-3) / 超(×0.2,-4)
- 最小Move=1、技能修正(隠れ身/水泳/登攀等)

## 5.2 移動
- 全力疾走: 1秒後+20%
- 行軍: Move×10マイル/日、技能成功+20%、地形倍率
- 跳躍: 立高=(6BM-10)in / 立幅=(2BM-3)ft / 助走×2
- 持上: 片手2×BL / 両手8×BL / 背負15×BL(1FP/秒) / 引12×BL / 微50×BL
- 水泳: BM/5 yd/s、5分毎水泳判定(荷重×2)、FP-1

## 5.3 回復
- 意識: HP>=1→15分自動 / HP<=0→1時間HT / HP<=-HP→12時間HT(1回)
- 自然: 24時間休息+HT成功=1HP
- 応急手当TL表: TL0-3:30分1d-4 / TL4:30分1d-2 / TL5:20分1d-2 / TL6-7:20分1d-1 / TL8+:10分1d

## 5.4 FP
- FP<1/3: Move/Dodge/ST半分
- FP<=0: 行動毎Will(気絶) / HP-1代用
- FP<=-maxFP: 虚脱
- 喪失要因: 戦闘10秒超=1FP+荷重 / 行軍=1FP+荷重/h / 飢3食=1FP / 脱8h=1FP / 睡眠1h毎Will
- 回復: 10分休=1FP / 睡眠8h+1FP 以降+1FP/h

## 5.5 環境
- 落下: (HP×速度)/100 d6(叩き)
- 炎: 部分1d-3/秒 全身1d-1/秒
- 熱80°F+: 30分毎HT/1FP
- 寒35°F-: 30分毎HT/1FP
- 窒息: HT×10秒息止→毎秒1FP→4分死亡
- 毒/病: 侵入口→HT抵抗→潜伏→効果
