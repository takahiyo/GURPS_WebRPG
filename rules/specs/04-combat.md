### 全力攻撃オプション
- 必中: 命中+4(遠隔+1)
- 二回: 同標的に2回
- フェイント即攻撃: フェイント→攻撃
- 渾身: 近接DMG+2 or +1/ダイス
- 制圧射撃: RoF5+連射で面制圧

## 4.4 命中修正
- 逆手:-4 / 足場:-2 / ST不足:-1/点
- 部位: 胴0 / 腕足-2 / 手足首-4 / 顔-5 / 頭頸部-7(DR+2,×4) / 目関節-8~-10
- SSR: 距離+速度 / SM加算 / Acc照準

## 4.5 能動防御
- よけ: BS+3-重荷+盾DB
- 受け: floor(技能/2)+3+盾DB (ナイフ-1/杖+2/素手-武器-3/累積-4回毎)
- 止め: floor(盾技能/2)+3+盾DB(1回/ターン)
- 後退: よけ/フェンシング+3 / 他+1
- 伏せよけ: 遠隔+3→伏せ
- アクロバット: 軽業成功+2/失敗-2

## 4.6 ダメージ計算
- 貫通 = max(0, BasicDmg - DR/ADI)
- 負傷 = floor(貫通 × 倍率)、最低1
- pi-×0.5 / pi×1.0 / cr×1.0 / burn×1.0 / cut×1.5 / pi+×1.5 / imp×2.0 / pi++×2.0

## 4.7 負傷影響
- 衝撃: 次ターンDX/IQ-負傷HP(max4)
- 大負傷: HP/2超→HT(失敗=転倒+朦朧+落とす、5差=気絶)
- 朦朧: 何もしないのみ、防御-4、HT回復
- HP<1/3: 移動力/よけ半分
- HP<=0: 毎ターンHT、失敗=気絶
- HP<=-HP: HT死亡(1-2差=致命傷)
- HP<=-5HP: 即死 / -10HP: 死体破壊
