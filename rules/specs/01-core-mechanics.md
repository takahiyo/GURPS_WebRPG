# GURPS 4th Edition System Specifications - Part 1: コアメカニクス

## 1.1 基本ダイス
- 3d6下方判定(Roll Under)
- 出目 <= 実効目標値 = 成功
- 3,4: 常に自動成功(クリティカル)
- 17,18: 常に自動失敗(18は常にファンブル)
- 目標値2以下: 能動防御以外は判定不可

## 1.2 成功度/失敗度
- MoS = 実効目標値 - 3d6出目(>=0)
- MoF = 3d6出目 - 実効目標値(>0)

## 1.3 クリティカル/ファンブル
- クリティカル: 3,4=常時 / 5(技能>=15) / 6(技能>=16)
- ファンブル: 18=常時 / 17(技能<=15) / 出目>=目標値+10

## 1.4 修正値
- 実効目標値 = 基本値 + 全修正値(累積)
- 3未満: 能動防御以外判定不可

## 1.5 対抗判定
- Quick: 両者判定、MoS比較、同値ならMoF比較
- Regular: 成功/失敗が分かれるまで継続

## 1.6 反応判定
- 3d6 + 修正値(高値良好)
- 表: 0以下破滅〜19以上最高(8段階)
