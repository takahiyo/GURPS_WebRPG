# Part 2: 能力値・二次的特性・CP算出ロジック

## 2.1 CP基本概念
- 開始CP: Feeble<25 / Average 25-50 / Competent 50-75 / Exceptional 75-100 / Heroic 100-200 / LargerThanLife 200-300 / Legendary 300-500 / Superhuman 500-1000
- 不利獲得CP上限: 開始CPの50%

## 2.2 基本能力値
| 属性 | CP/level | 判定対象 |
|---|---|---|
| ST | ±10 | 近接DMG/BL/HP |
| DX | ±20 | 運動/手先/命中/BS |
| IQ | ±20 | 知識/精神技能/Will/Per |
| HT | ±10 | スタミナ/毒抵抗/FP/BS |

- 1-6:障害 / 8-9:平均以下 / 10:平均 / 13-14:優秀 / 15+:驚異的 / 20+:神級

## 2.3 副能力値
| 名称 | 基準 | CP/level |
|---|---|---|
| HP | ST | ±2 |
| Will | IQ | ±5 |
| Per | IQ | ±5 |
| FP | HT | ±3 |
| BS | (DX+HT)/4 | ±5/±0.25 |
| BM | BS整数部 | ±5/±1 |
| Dodge | BS+3-重荷 | - |
| BL | ST²/5(lbs) | - |
