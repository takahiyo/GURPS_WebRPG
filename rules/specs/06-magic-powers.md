# Part 6: 魔法・錬金術・超能力・特徴カスタマイズ

## 6.1 魔法
- 呪文: IQ/難 or IQ/至難 技能、技能なし値なし
- 魔法の素質(Magery): IQ基準に加算
- 集中: 1秒→発動、負傷でWill-3中断
- 技能レベル効果: 15=移動可/FP-1 / 20=準備半分/FP-2 / 25=準備1/4 / 30+=5Lv毎に更に半分
- FP消費: HP代用可(-1目標値/HP)、パワーストーン可
- マナ: 無/疎(-5)/並/密(素質不要)/濃密(FP即還元+全失敗がファンブル)
- 呪文クラス: 通常/範囲/白兵/射撃/防御/情報/抵抗/魔化
- 魔化: Quick&Dirty / Slow&Sure(1FP/日)

## 6.2 錬金術
- 錬金術(IQ/難): 薬品/霊薬作成
- 形態: 水薬/粉薬/煙薬/塗薬

## 6.3 超能力
- パワー修正(-10%): 超能力属性、中和/阻止/装置による妨害リスク
- 6系統: アンチサイ/ESP/ヒーリング/テレパシー/テレポーテーション/PK
- 才能: 5CP/level、系統内全判定+level

## 6.4 特徴修正(増強/限定)
- 増強(+%): 持続延長/力場/範囲等
- 限定(-%): 準備時間/パワー修正/FPConsumption/自制値
- 最終CP = round(基本CP × (1 + (増強%-限定%)/100))
- 限定上限: 最大-80%
- 自制値: 12=標準 / 15=半分CP / 9=1.5倍 / 6=2倍
