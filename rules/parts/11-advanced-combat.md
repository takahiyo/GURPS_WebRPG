# Part 11: 戦闘・感覚・環境の詳細ロジック

## 11.1 感覚判定
- 基本: 3d6 <= 知覚
- 視覚: 遠距離/暗闇修正
- 聴覚: 隠密対抗/背後察知
- 味覚/嗅覚: 毒検知
- 隠蔽物発見: 「観察」「捜索」技能代用可

## 11.2 恐怖判定
- 判定: 3d6 <= 意志
- 失敗: 失敗比+2d秒間、朦朧
- 致命的失敗: 気絶/精神的後遺症

## 11.3 命中部位(簡略)
- 胴体: 修正0
- 頭部: 大ペナルティ/DR無視/ダメ増加
- 手足: 武器落とし/移動制限

## 11.4 SSR表
- 距離yd+標的速度 vs SM
- 2yd=0, 3yd=-1, 5yd=-2, 7yd=-3, 10yd=-4, 15yd=-5, 20yd=-6, 30yd=-7, 50yd=-8, 70yd=-9, 100yd=-10

## 11.5 特殊武器効果
- アーマーディバイダー(2): DRを2で割る
- 1/2D: 超過で基本ダメ半分
- 反動(Rcl): 連射、出目がRcl良くなる毎に+1発命中

## 11.6 ダメージ深刻度
- 衝撃(-最大4): 負傷後次ターンDX/IQ
- ノックダウン/朦朧: HP/2超一撃→HT転倒/朦朧
- 致命傷: HP0以下死亡判定1-2差で発生、30分毎HT継続

## 11.7 環境ハザード
| 種別 | 効果 |
|---|---|
| 炎(部分) | 毎秒1d-3燃焼 |
| 炎(全身/引火) | 毎秒1d-1燃焼 |
| 熱(80°F以上) | 30分毎HT、失敗で1FP |
| 寒冷(35°F以下) | 30分毎HT、失敗で1FP |
| 衝突 | (HP×速度)/100 d6 |
| 毒 | 摂取/吸入/接触/注入、遅延時間 |
| 窒息 | 毎秒1FP→0FPで気絶→4分死亡 |

## 11.8 疲労蓄積
- 長時間戦闘(10秒超): 1FP+重荷修正
- 飢え: 3食抜く毎に1FP
- 脱水: 水不足、8時間毎に1FP
- 睡眠不足: 超過時間毎Will、失敗で1FP
