# Part 4: 技能編 (Skills)

## 4.1 技能の基本
- 技能レベル = 依拠属性 + 習得相対レベル
- 判定: 3d6 <= 技能レベル
- 難易度: 易(E) / 並(A) / 難(H)
- 依拠属性: DX / IQ / HT 等

## 4.2 技能習得コスト表
| 技能レベル | 易(E) | 並(A) | 難(H) |
|---|---|---|---|
| 属性-3 | - | - | 1CP |
| 属性-2 | - | 1CP | 2CP |
| 属性-1 | 1CP | 2CP | 4CP |
| 属性+0 | 2CP | 4CP | 8CP |
| 属性+1 | 4CP | 8CP | 12CP |
| 属性+2 | 8CP | 12CP | 16CP |
| +1/level | +4CP | +4CP | +4CP |

## 4.3 技能の初期値 (Defaults)
- 易: 属性-4
- 並: 属性-5
- 難: 属性-6（初期値なしの技能もあり）
- 20の法則: 初期値計算時、属性>20は20として扱う

## 4.4 技術レベル (Tech Level / TL)
- 科学技術依存技能はTL指定必須（例: 医学/TL3）
- 異TLの道具使用時はペナルティ

## 4.5 技能カテゴリ
- 身体・運動系: アクロバット、登攀、脱出、隠れ身、水泳 等
- 戦闘・武器系: 格闘、空手、近接武器、射撃武器、盾、戦術 等
- 社会・対人系: 演技、外交、変装、威圧、指導力、商人、街頭知識 等
- 技術・学術系: コンピューター、電子機器、応急処置、医学、修理、自然科学、社会科学 等
- 野外・サバイバル系: 地域知識、自然知識、ナビゲーション、乗馬、追跡、罠 等
