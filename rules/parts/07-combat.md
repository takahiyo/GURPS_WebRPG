# Part 7: 戦闘システム編

## 7.1 戦闘ターンの流れ
- 1ターン=1秒
- 行動順: 基本速度(BS)降順
  - 同値: DX高い方→ダイス
- 構造: (1)防御リセット (2)動作選択 (3)動作実行

## 7.2 動作 (Maneuvers)
| 動作 | 移動 | 攻撃 | 防御 | 備考 |
|---|---|---|---|---|
| 何もしない | 不可 | 不可 | 可 | 気絶/転倒中 |
| 移動 | 全移動力 | 不可 | 可 | |
| 姿勢変更 | 変更有 | 不可 | 可 | 立/座/膝/這/横 |
| 照準 | 不可 | 次ターンAcc加算 | 可 | |
| 攻撃 | 不可 | 1回 | 可 | 準備済み武器 |
| 全力攻撃 | 最大1歩 | 特殊 | 不可 | 命中+4 / 2回 / ダメ+2 |
| 全力防御 | 最大1歩 | 不可 | +2 | 二重防御可 |
| 移動攻撃 | 全移動力 | -4(上限9) | 可 | |
| 集中 | 不可 | 不可 | 可 | Will-3で中断判定 |
| 待機 | 不可 | 次ターン準備 | 可 | 武器抜く/装填/構え直し |

## 7.3 姿勢修正
| 姿勢 | 攻撃 | 防御 | 射撃標的 | 移動 |
|---|---|---|---|---|
| 立ち | 0 | 0 | 0 | 通常 |
| しゃがみ | -2 | 0 | -2 | 2/3 |
| ひざまずき | -2 | -2 | -2 | 1/3 |
| 這い | -4 | -3 | -2 | 1/3 |
| 座り | -2 | -2 | -2 | 不可 |
| 横臥 | -4 | -3 | -2 | 1yd/秒 |

## 7.4 命中修正
- 共通: 足場-2, 逆手-4, ST不足1につき-1
- 遠隔: SSR表(射程yd+標的速度), SM, 照準Acc(+1/2秒/+2/3秒)

## 7.5 能動防御
- よけ: BS+3 - 重荷修正
- 受け: (技能/2)+3 + 盾DB (フェンシング武器+α, ナイフ-ペナルティ)
- 止め: (盾技能/2)+3 (盾装備必須)

## 7.6 防御修正
- 朦朧: -4
- 全力防御: +2
- 背後: 防御不可
- 見えない敵: 聴覚成功で-4、失敗で不可
