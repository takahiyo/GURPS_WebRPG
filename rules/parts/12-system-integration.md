# Part 12: システム統合と最終実装データ

## 12.1 負傷・回復しきい値
- 意識判定: HP<=0でHT(修正: -|現在HP|/最大HP)、失敗=気絶
- 死亡判定: HP=-最大HP×1/2/3/4でHT、失敗=死亡
- 即死: HP=-最大HP×5
- よろめき(Reeling): HP<最大HP/3 または FP<最大FP/3 → Move/Dodge半分(切上)
- 自然回復: 1日休息毎HT成功=1HP
- 応急処置TL表:
  - TL0-3: 30分/1d-4(最低1)
  - TL4: 30分/1d-2
  - TL5: 20分/1d-2
  - TL6-7: 20分/1d-1
  - TL8: 10分/1d

## 12.2 クリティカル詳細
- クリティカル成功(攻撃): 防御側防御不可、ダメージ最大値適用
- クリティカル失敗(防御): 転倒/武器落とし
